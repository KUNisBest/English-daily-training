# English-daily-training

一个 English training skill：每天带你完成英语词汇复习 + 阅读训练，像私人教练一样安排节奏、滚动复习、查漏补缺。基于 100 天真实每日训练的实战经验提炼而成。

## 它做什么

每天固定四步，全程中文交互（题干英文、答中文）：

1. **回顾昨日** — 昨天的生词和错词一次性列出（不拆分），答错的明天继续考，直到记住
2. **10 词测验** — 8 个学习中的词 + 2 个"久攻老将"（防止毕业就忘）
3. **追加新词** — 数量 = 当天测验答对数，成绩好就多学、差就少学
4. **阅读训练** — 约 400 词科普短文 + 5 道题（正确选项同义转述，杜绝"记住原文位置"式答题）

每个词带 🔴🟡🟢 状态（累计答对 0 次 / 1-2 次 / 3 次毕业），答对 3 次毕业。每次混淆（比如把 legacy 答成"合法"）都会写进该词的防混淆备注，形成个人化的易错档案。

## 安装

### 方式一：直接复制（推荐）

把整个 `english-daily-training` 文件夹复制到 Claude Code 的 skills 目录：

- Windows：`C:\Users\<你的用户名>\.claude\skills\`
- macOS / Linux：`~/.claude/skills/`

新开一个窗口即可生效。

### 方式二：.skill 安装包

在 Releases 下载 `english-daily-training.skill`，然后在 Claude Code 里用 `/install` 安装。

## 使用

在 你的agent 里说：

> 今日训练

第一天它会问三件事（都有默认值，直接回"都用默认"即可）：

1. 目标水平：CET-6（默认）/ CET-4 / 考研英语 / 托福 / 雅思 / 自定义
2. 答题方向：E→C（默认）/ C→E / 混合
3. 每日测验词数：10（默认）

之后每天只说"今日训练"，它会自己判断进度、接着做。

## 数据存在哪

所有状态（词表、阅读记录）存在 skill 目录的 `state/` 文件夹里——每个安装者各用各的，互不影响。

⚠️ 升级或重装 skill 前，请先备份 `state/` 文件夹。

## 常见问题

- **前几天测验不到 10 个词？** 正常。🟡 和 🟢 是随训练慢慢积累的，词表长大后就满 10 题了。
- **想换水平或方向？** 直接说"改成考研英语"，它会记下来。
- **中途离开了？** 下次说"今日训练"，它会从没做完的步骤继续，不重做。
- **状态文件丢了？** 说一声，它会重新初始化（词表从头开始）。
